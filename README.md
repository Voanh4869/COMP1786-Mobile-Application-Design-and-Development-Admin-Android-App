# Project Expense Tracker - Admin Application (COMP1786)

## Overview
This repository contains the **Native Android (Admin)** source code for the Project Expense Tracking system developed for the COMP1786 Mobile Application Design and Development module at the University of Greenwich.

This application is built with **Java** and utilizes a local **SQLite database** for offline administrative data entry and management. It is designed to work in tandem with a companion Hybrid User App (.NET MAUI) by synchronizing data through a shared **Firebase Realtime Database**.

---

## System Requirements & Prerequisites

To compile and run this Android application, ensure your development environment meets the following requirements:

* **IDE:** Android Studio (Latest version recommended)
* **SDK:** Minimum Android SDK Level 24 (Nougat) / Target SDK Level 34
* **Java:** JDK 17 or higher
* **Device:** Android Emulator or physical Android device enabled for USB Debugging

---

## Compilation, Installation, and Running Instructions

Running the Application in Android Studio
Open Android Studio.

Select File > Open and navigate to the cloned repository directory.

Allow Gradle to sync and build the project structure. This may take a few minutes depending on your internet connection.

If prompted, update the Android Gradle Plugin to match your Android Studio version.

Select an active Android Emulator or connect a physical device via the device manager dropdown.

Click the Run 'app' button (or press Shift + F10) to compile, install, and launch the application on your device.
